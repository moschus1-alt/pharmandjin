# Pharmacy & Jinsang

**오늘도 영업합니다** — 한국 약국을 배경으로 한 모바일 가로·PC 웹 5레인 디펜스입니다. 귀여운 약사와 약국 도구로 스무 번의 근무를 지킵니다. 실제 판매·결제·광고는 없습니다.

## v0.2 변경

- 아군·방문객·경찰·보스·엔딩과 세 근무지 배경을 새 2D 카툰 그래픽으로 교체했습니다. 기존 원본은 보존하며 새 그림은 `assets/redesign/`에서 사용합니다.
- 로비, 근무표, 팀 편성, 전투 HUD와 대화상자를 크림·민트·코랄 색상으로 정리했습니다. 허브 직원 터치, 완료한 근무 수, 필수 카드 선택 상태를 실제 게임 상태와 연결했습니다.
- 20단계를 초반 학습 → 중반 유닛 조합 → 후반 도전의 흐름으로 재조정했습니다. 편성 화면에서 각 단계의 목표·난이도·예상 게임 시간을 확인할 수 있습니다. 새 적 소개, 웨이브 간격, 포장갑옷 대응도 단계별로 구성했습니다.
- 겹친 근거리 적을 투사체가 지나치던 문제와 직원 뒤 연고칼의 공격 사거리를 수정했습니다.
- 시작에 필요한 이미지는 병렬로 불러오고 엔딩 이미지는 진입 시 불러옵니다. 엔딩 로딩 실패 시 재시도할 수 있으며, 취소·탭 전환·세로 화면에서도 일시정지 상태를 유지합니다.

## 실행

이 폴더에서 `node server.mjs`를 실행한 뒤 **http://127.0.0.1:8787** 을 엽니다. Windows에서는 `게임 시작.cmd`를 더블클릭할 수도 있습니다. 별도 패키지 설치나 빌드가 필요하지 않습니다. 실행 중 서버 창을 닫으면 게임 파일 제공이 중지됩니다. 파일을 직접 더블클릭하는 `file://` 방식은 사용하지 마세요.

14종의 동료와 도구 중 최대 **9종**을 선택할 수 있습니다. 판매대와 공격 유닛이 필요하며, 포장갑옷이 등장하는 일부 단계에서는 돌돌이포장기도 필수입니다.

## 조작

- 판매대를 배치하고 생성된 **₩ 돈 아이콘을 직접 터치/클릭**합니다.
- 카드를 선택한 뒤 빈 칸을 터치해 배치합니다. 공격은 자동입니다.
- **퇴근 도장**을 선택하고 유닛을 누르면 제거합니다. 환급은 없습니다.
- **Ⅱ**는 일시정지, **×1/×2**는 전투 속도입니다.
- **112**는 근무당 전체 1회 자동 출동합니다. 전장의 일반 적을 연행하고 왕진상은 뒤로 밀어냅니다. 왕진상의 체력과 페이즈는 유지됩니다. 이후 어느 레인이든 재돌파하면 패배하며, 앞으로 등장할 웨이브는 남습니다.
- 스테이지 클리어 직후 진행도를 저장합니다. 전투 중 새로고침하면 마지막 클리어까지만 복원됩니다.
- 모바일은 가로로 사용합니다. 배경 음악과 효과음은 첫 입력 이후 시작합니다.

## 구성

- `src/data.js`: 14종 유닛, 일반 적 11종과 별도 최종 보스, 20스테이지 목표·난이도·예상 시간, 웨이브·밸런스·게임 대사.
- `src/sim.js`: 전투 시간·배치·공격·돈·경찰·보스.
- `src/app.js`, `src/render.js`: 메뉴·입력·Canvas 화면·애니메이션·상황극·엔딩.
- `src/ko.js`: 한국어 UI 문자열. `src/save.js`: 버전된 로컬 저장.
- `src/audio.js`: 독창적인 Web Audio BGM·효과음.
- `assets/redesign/`: 현재 사용하는 Codex 생성 v2 원본과 `manifest-v2.json`의 실제 프레임 영역. `assets/`의 v1 원본은 이력 보존용입니다.
- `src/qa.js`, `tests.mjs`: 전투 규칙 및 정상 자금·쿨다운 기반 자동 전략 검사.
- `lifecycle-tests.mjs`: 실제 App 메서드의 엔딩 로딩·실패·재시도·취소·일시정지 회귀 검사.
- `docs/MASTER_BUILD_PROMPT.md`: 제작 기준 전체.
- `docs/CHARACTER_SPRITE_PIPELINE.md`, `docs/ASSET_PROVENANCE.md`: 아트 규격과 출처.
- `docs/ART_V2_PROMPTS.md`, `docs/REDESIGN_BALANCE_V2.md`: v2 이미지 생성 기록과 단계별 밸런스 설계.
- `qa/`: 실제 검사 결과와 화면 증거.

## 검증 방식

별도 패키지 설치 없이 프로젝트 폴더에서 실행합니다.

```text
node tests.mjs
node --test renderer-tests.mjs lifecycle-tests.mjs
```

첫 명령은 전투 규칙과 20스테이지 자동 전략을 검사합니다. 두 번째 명령은 그림 병렬 로드와 발 기준선, 엔딩 요청 중복 방지, 실패 후 재시도, 취소 후 늦게 도착한 응답, 재요청 중 이전 응답, 백그라운드·세로 화면의 일시정지, 첫 자막을 확인합니다. `npm test`는 두 검사를 모두 실행합니다.

자동 검사는 실제 화면·터치·청취 검증을 대신하지 않습니다. 브라우저 검증에는 `?dev&test=검사이름`으로 별도 저장 키를 사용합니다. 일반 주소에서는 개발 도구가 노출되지 않습니다. 이미지 알파와 프레임 경계 수치는 `qa/asset-v2-report.json`, 밸런스 검증 조건과 한계는 `docs/REDESIGN_BALANCE_V2.md`를 참고하세요. 이전 버전의 검사 기록은 `docs/QA_REPORT.md`에 보존되어 있습니다.

## 범위와 한계

밸런스는 자동 전략과 플레이테스트를 바탕으로 조정합니다. 자동 클리어 결과가 모든 플레이어의 체감 난이도나 모든 실기기의 동작을 보장하지는 않습니다. 예상 시간은 게임 시간 기준이며 배속, 배치 전략과 재도전에 따라 실제 소요 시간은 달라집니다. 상용 서비스·외부 에셋·외부 음원에 의존하지 않습니다.
