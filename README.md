# Pharmacy & Jinsang

한국 약국을 배경으로 한 모바일 가로·PC 웹 5레인 디펜스. 실제 판매·결제·광고가 없는 로컬 웹 게임입니다.

## 실행

이 폴더에서 `node server.mjs`를 실행한 뒤 **http://127.0.0.1:8787** 을 엽니다. Windows에서는 `게임 시작.cmd`를 더블클릭할 수도 있습니다. 별도 패키지 설치나 빌드가 필요하지 않습니다. 실행 중 서버 창을 닫으면 게임 파일 제공이 중지됩니다. 파일을 직접 더블클릭하는 `file://` 방식은 사용하지 마세요.

최대 **9종**을 선택할 수 있습니다. 새 공격 유닛: 절구·분무기·냉찜질팩·캡슐연사기·약봉투발사기.

## 조작

- 판매대를 배치하고 생성된 **₩ 돈 아이콘을 직접 터치/클릭**합니다.
- 카드를 선택한 뒤 빈 칸을 터치해 배치합니다. 공격은 자동입니다.
- **퇴근 도장**을 선택하고 유닛을 누르면 제거합니다. 환급은 없습니다.
- **Ⅱ**는 일시정지, **×1/×2**는 전투 속도입니다.
- **112**는 근무당 전체 1회 자동 출동합니다. 전장에 있는 모든 적(왕진상 포함)을 연행하고, 이후 어느 레인이든 재돌파하면 패배합니다. 앞으로 등장할 웨이브는 남습니다.
- 스테이지 클리어 직후 진행도를 저장합니다. 전투 중 새로고침하면 마지막 클리어까지만 복원됩니다.
- 모바일은 가로로 사용합니다. 배경 음악과 효과음은 첫 입력 이후 시작합니다.

## 구성

- `src/data.js`: 14종 유닛, 10종 적, 20스테이지, 웨이브·밸런스·게임 대사.
- `src/sim.js`: 전투 시간·배치·공격·돈·경찰·보스.
- `src/app.js`, `src/render.js`: 메뉴·입력·Canvas 화면·애니메이션·상황극·엔딩.
- `src/ko.js`: 한국어 UI 문자열. `src/save.js`: 버전된 로컬 저장.
- `src/audio.js`: 독창적인 Web Audio BGM·효과음.
- `assets/`: Codex가 생성한 버전된 원본 아틀라스와 실제 프레임 영역.
- `src/qa.js`, `tests.mjs`: 전투 규칙 및 정상 자금·쿨다운 기반 자동 전략 검사.
- `docs/MASTER_BUILD_PROMPT.md`: 제작 기준 전체.
- `docs/CHARACTER_SPRITE_PIPELINE.md`, `docs/ASSET_PROVENANCE.md`: 아트 규격과 출처.
- `qa/`: 실제 검사 결과와 화면 증거.

## 검증 방식

`node tests.mjs`는 전투 규칙과 20스테이지의 자동 전략을 검사합니다. 이것은 실제 화면·터치·청취 검증을 대신하지 않습니다. 브라우저 검증에는 별도 테스트 저장 키와 개발 모드를 사용합니다. 일반 주소에서는 개발 도구가 노출되지 않습니다. 상세한 검증 범위와 미검증 항목은 `docs/QA_REPORT.md`를 참고하세요.
