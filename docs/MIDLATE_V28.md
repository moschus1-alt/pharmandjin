# 중후반 조합 점검

8·9·12·15·18·20단계, 해금 가능한 베테랑/절구/에프킬라/캡슐/약봉투 조합, 3시드씩 총75회. 0.6초 간격 자동 행동이며 돈/비용/쿨다운을 준수. 전부 클리어했으나 15·18단계는 경찰 의존이 높았고, 20단계는 특수 유닛을 설치하기 전에 경찰로 끝나므로 보스 조합 밸런스 근거에서 제외한다. 자동 전략에는 근접 배치 등 편향이 있어 인간의 재미 평가를 대체하지 않는다.

고정 고HP 표적12초 비교에서 에프킬라162/486(한 명/인접 세 명), 돌돌이180/510(한 명/같은 줄 세 명), 약봉투240/720(한 명/인접 세 명), 베테랑252로 역할 차이를 확인. 초기 준비/발사체 비행을 포함한 시험 피해이며 상시 DPS가 아니다.

변경: 포장갑옷을9단계 최대2,10단계 최대3,12·18단계 최대4로 제한하고14초 이상 간격, 일반 적 총수와5레인 보존. 갑옷 해제 시 말풍선 수정. 공격 수치 유지. 브라우저844×390에서 실제 돌돌이 명중으로 갑옷0 확인. 기존 보스3페이즈 규칙 검증과20단계 회귀 통과; 정상 전투로 보스 완주 검증은 이번 비교에서 미완료.
