# 캐릭터 파이프라인

## 2026-10-07 리디자인 v2

새 파일은 `assets/redesign/`에 보관하고 기존 v1 원본을 덮어쓰지 않는다. 내장 Codex imagegen으로 생성한 팀 4×4(16개 중 14개 전투 사용), 방문객 4×4(16개), 포장갑옷 1개, 엔딩 3×2(6개) 아틀라스다. 측면 레인 게임이므로 이 16개는 서로 다른 유닛이며 4방향 보행 시트가 아니다. 기존 idle/walk/attack/hurt/death 상태와 delta time 기반 절차적 동작을 유지한다.

`manifest-v2.json`은 기존 논리 이름을 새 `source` 파일에 매핑한다. 팀 아틀라스 하나를 아군/추가 유닛이 공유하며 실제 이미지 요청은 한 번만 한다. 원본 픽셀을 편집하지 않고 실제 투명 여백을 찾아 프레임 경계를 측정했다. 알파 값 8 초과인 실루엣이 각 영역 경계와 접하지 않음을 확인하고, 가능한 4px의 투명 여백을 포함했다. 중심은 프레임 가로 중앙, 발/기계 바닥은 프레임 하단으로 고정한다. 검사 수치와 프레임 순서는 `qa/asset-v2-report.json`에 기록한다.

아군은 오른쪽, 적은 왼쪽을 향한다. 방문객 11번 경찰(0부터 세는 인덱스)은 오른쪽을 향하므로 연행 장면에서도 수평 반전 없이 그린다. 오른쪽으로 연행되는 일반 적에만 `flip:true`를 적용한다. 이 방향 처리는 현재 `src/render.js`의 연행 렌더링과 일치한다. 세 배경은 각각 동네약국 아침, 병원 앞 오후, 심야 우천의 별도 원본이다. 엔딩 이미지는 필요 시 로드하고 실패하면 재시도할 수 있다. 모든 그림은 캔버스에서 상태·효과·크기·잘림을 다시 확인한 후 공개한다. 생성 프롬프트와 엔딩 시안의 광채·장식 정리 경위는 `docs/ART_V2_PROMPTS.md`에 보관한다.

## 방식
Codex image_gen의 투명 RGBA 아틀라스를 사용한다. 현재 v2의 팀과 방문객은 각각 4×4이고 엔딩은 3×2이며, 이전 v1 아군 3×3 원본도 보존한다. 각 셀은 정해진 행 우선 ID다. 원본을 버전 보존하고 alpha bounding box로 셀 내 실루엣을 검사한다. 논리 위치는 발 바닥 중앙이다. 실제 그리기는 bbox 비율을 유지하며 셀 바깥 파편은 사용하지 않는다.

## 상태
idle: 호흡, walk: 발 기준 몸 기울기/보행 박자, attack: 별도 준비·발사·복귀, hurt: 짧은 반동과 색 변화, death: 전용 회전·낙하·퇴장. 공격 이벤트는 simulation update에서 1회 발생. 렌더는 피해를 생성하지 않는다. 기계는 발 대신 바닥 기준. 시럽/포장/연고/경찰/보스 KO는 전용 오버레이.

## 검사
원본 크기·alpha·셀 경계·bbox, 상하 레인·보스 최대 동작·모바일 viewport, 방향과 발 기준선을 런타임 검사. 4방향 시트는 사용하지 않으므로 16보행 프레임 검사는 해당 없음.
