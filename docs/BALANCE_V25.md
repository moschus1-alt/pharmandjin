# 공격 유닛 역할 조정

- 모든 일반 스테이지(2~20)에서 기존 적 수를 유지하며 누락 레인에 후반 적을 재배치. Stage 1은 기존 5레인 튜토리얼 보존. 19스테이지 ×100시드 검사 통과.
- 베테랑: 비용175→200, 피해20×2→18×2, 주기1.4→1.6초, 카드 재사용10→12초. 한 칸 화력 집중용; 초보약사의 자원 효율 유지.
- 시럽병100→75: 감속 지원. 냉찜질팩100→75: 준비 후 위기 시간 확보. 약봉투225→200: 여러 레인 밀집 대처.
- 나머지 공격 수치 유지. 관통/3레인/근거리/곡사/빠른 연사/일회성 범위의 용도와 약점을 선택 화면에서 안내.
- 40개 규칙 및20스테이지 자동 플레이 통과. 640×360 선택 화면에서 베테랑 설명 확인.
