# 리디자인 v0.2 검증 · 2026-10-07

## 실제 게임에 연결한 변경

- `assets/redesign/`: Codex에서 생성한 팀·방문객·갑옷·엔딩 RGBA와 세 약국 배경. 이전 원본은 보존했다. `src/render.js`에서 기존 유닛/적 ID를 새 그림에 연결하며 전투판, 투사체, 피격 효과, 경찰 표시를 다시 그린다.
- `src/app.js`, `style.css`: 허브, 근무표, 편성, 전투 HUD, 대화창을 크림·민트 계열로 통일했다. 스테이지 목표와 난이도, 예상 시간을 표시한다.
- `src/data.js`, `src/sim.js`: 20단계의 소개/연습/혼합 구성을 재조정하고 연고칼 사거리를 165로 통일했다. 가까이 겹친 적에게 긴급 배치한 투사체가 빗나가던 문제도 수정했다.
- 엔딩 그림은 필요할 때 요청하며, 실패 안내에서 재시도할 수 있다. 허브 캐릭터 터치와 엔딩 자막 문제를 수정했다. 초기 이미지 요청은 병렬이며 공유 아틀라스를 중복 요청하지 않는다.
- 음악/효과음은 기존 코드 기반 Web Audio를 유지한다. 새 외부 에셋이나 음원 의존성은 없다. 저장 키와 해금 순서는 유지한다.

## 확인한 결과

- 규칙 검사 50/50, 기본 캠페인 20/20 통과.
- 렌더러 검사 5개, 엔딩 전환 검사 6개 통과. 실제 앱 메서드로 중복 로드, 오류 재시도, 취소 후 늦은 응답, 숨겨진 탭과 세로 화면 상태를 검사했다.
- 세 시드의 기본 전략 59/60, 0.5초마다 한 행동을 하는 전략 59/60. 후자의 초반 1–6단계는 18/18 경찰 없이 승리했다. 19단계 한 시드의 패배와 일부 긴 클리어 시간은 `REDESIGN_BALANCE_V2.md`에 공개한다.
- 원본 알파와 사용 영역 37개를 검사했다. 팀/방문객 시트는 각 16개 영역, 엔딩은 6개, 갑옷은 1개다. 경계 안의 실루엣과 투명 여백 수치는 `qa/asset-v2-report.json`에 있다.
- 로컬 HTTP에서 허브 캐릭터 터치 대사, 편성과 전투 진입, 긴급 배치 실제 클릭, 직원 뒤 연고칼 타격, 일시정지/재시작, 엔딩 실패 후 재시도를 확인했다. 긴급 배치에서는 5초 후 겹친 첫 적 HP 200→140, 뒤 적 200을 확인했다.
- 667×375와 568×320 실제 iframe 화면에서 편성 스크롤, 9장 전투 HUD, 버튼과 전장 분리, 세로 회전 안내 및 가로 복귀 후 재개 안내를 확인했다. 568×320 손님 목록이 접히는 문제를 수정하고 끝 항목까지 스크롤 가능한 것을 확인했다. 이는 데스크톱 브라우저 크기 검사이며 실제 휴대폰 하드웨어 검사는 아니다.

## 범위와 제한

자동 전략은 정상 자금·쿨다운·승리 조건을 사용하지만, 사람의 판단 속도와 재미를 보증하지 않는다. 예상 시간은 목표이며 제한시간이 아니다. 특히 9/12/18/19/20단계는 실제 플레이 피드백에 따라 추가 조정할 수 있다. 오디오 합성과 기존 음악은 변경하지 않았으며 이번 릴리스에서 새로운 음악을 제작했다고 주장하지 않는다.

검증 도구와 테스트용 저장값은 로컬 전용이며 배포 파일에 포함하지 않는다. 공개 배포 결과는 해당 커밋의 GitHub Pages 실행 기록으로 확인한다.
