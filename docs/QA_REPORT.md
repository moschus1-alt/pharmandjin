# Pharmacy & Jinsang v0.1 검증 보고서

검증일: 2026-09-07. 로컬 HTTP + Microsoft Edge(Chromium).

## 확인한 결과
- 핵심 규칙 30개 통과. 실제 투사체 피해, 9종 유닛, 적 상태, 돈 수집, 경찰 재돌파, 보스 임계값, 이벤트 자원 보존, 재시작 초기화 포함.
- Node tests.mjs 재실행: 규칙 30/30, 20스테이지 시뮬레이션 모두 승리.
- 브라우저 DOM 버튼 및 캔버스 PointerEvent 입력을 통한 1~20스테이지 승리·해금·즉시 저장 확인. 보스 3페이즈 진입 확인. 상세 기록: qa/browser-campaign-v01.json.
- 이 캠페인 검사는 가속된 QA 드라이버로 수행했으며, 모든 구간을 실시간 수동 조작한 검사는 아님. Stage 2 이후 렌더링은 표본 프레임으로 검사. 자원·HP·쿨다운 강제 변경이나 강제 승리는 사용하지 않음.
- 640×360(16:9), 720×360(18:9), 780×360(19.5:9), 800×360(20:9), 1024×768, 1366×768, 1920×1080: 화면 넘침 없음, 첫 칸 배치 좌표 일치, 주요 전투 버튼 44px 이상.
- 일시정지 10초 동안 시뮬레이션 상태 불변, ×2에서 입력 시간 5초가 시뮬레이션 10초로 진행.
- 잘못된 저장 JSON 기본값 복구, 미래 버전 데이터 덮어쓰기 방지, 진행·설정·튜토리얼 재읽기 확인.
- visibilitychange 상태 모의 주입으로 백그라운드 정지 및 복귀 시 재개 확인창 확인. 실제 OS 탭 전환/휴대폰 잠금 검사는 별도 필요.
- 엔딩 청소/카운터/커피 및 손님 반응 포즈 실제 브라우저 확인. 최종 타이틀, 시계 전환 및 KO 표본 화면 저장.
- 캐릭터 아틀라스 실제 알파 채널과 프레임 범위 검사. 균일 셀 가정 대신 실제 그림 경계 사용. 엔딩 이미지의 불투명 체크무늬 버전은 제외.
- 브라우저 pageerror: 0. 오디오 컨텍스트 생성 및 일시정지 시 예약 노드 정리 확인.

## 남은 품질 검수
- 현재는 플레이 가능한 v0.1이며, 마스터 프롬프트의 최종 상업용 수준 완성도 판정은 아님.
- 실제 iOS/Android 기기, 노치 safe-area, 물리 터치, 기기 잠금/복귀 및 장시간 성능 검수 필요. 현재 해상도 검사는 데스크톱 브라우저 뷰포트 검사.
- BGM/SFX 청감, 반복 피로, 기기별 볼륨 균형은 직접 청취 검수 필요.
- 사람의 첫 플레이 난이도·가독성·후반 길이 검수 필요. 수치는 v0.1 테스트 기준이며 최종 밸런스가 아님.
- 생성된 정지 포즈에 절차적 이동/공격/피격/사망을 결합한 방식. 완전한 프레임 애니메이션 제작물이 아님.

qa/ 폴더에 규칙·캠페인·추가 검사 JSON 및 화면 증거를 보관한다. 테스트 저장은 pj-test-* 키를 사용하며 일반 플레이 저장과 분리한다.
