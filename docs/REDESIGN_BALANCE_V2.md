# 단계 구성과 전투 수정 V2 · 2026-10-07

초반에는 경제와 전방 방어를 배우고, 중반에는 새 도구와 적의 대응 조합을 익히며, 후반에는 여러 레인을 관리하도록 20단계의 등장 구성을 다시 설계했다. 새로운 기능이나 영구 능력치는 추가하지 않았다.

## 변경 범위

- 적 종류를 매번 무작위로 추첨하던 방식에서 단계별로 정한 소개·연습·혼합 묶음으로 변경했다. 새 적은 두 번째 묶음에서 반드시 등장한다. 후기 묶음의 레인 순서만 시드로 변한다. 초반의 핵심 소개 위치는 고정한다.
- 준비 시간은 18초 또는 22초, 이후 적 생성 사이 최대 공백은 14초다. 묶음 사이 휴식은 12–14초, 보스 전초는 8초다. 12단계 마지막 묶음 앞 12초는 그대로 유지한다. 이는 생성 간격이며, 전장에 적이 없는 시간이 14초 이하라는 보장은 아니다.
- 기존 20단계 ID, 14개 유닛 ID와 해금 순서, 저장 구조, 0원 시작과 하늘 돈, 피해량·가격·공격 주기·적 체력, 경찰 규칙은 유지한다. 9·10·12·18단계는 돌돌이 필수이며 갑옷 수 제한과 14초 간격도 유지한다. 9단계 갑옷 2명은 중앙 레인으로 소개한다.
- 10·19단계 이벤트의 종류와 효과는 유지한다. 짧아진 단계의 기준 시간에서도 48% 시점에 발생한다. 20단계 보스 등장 70초, 체력·3페이즈·지원군·경찰 상호작용은 변경하지 않았다.
- 각 단계에 goal, difficulty(1–5), estimatedSeconds, waveGroups를 제공한다. 예상 시간은 안내용 목표이며 클리어 제한시간이나 보장값이 아니다.

## 전투 결함 회귀

- 급히 배치한 공격 유닛과 겹친 적을 투사체가 건너뛰던 문제: 첫 발사 틱에서만 유닛과 총구 사이를 충돌 구간에 포함한다. 기존 전방 감지 허용 범위보다 뒤인 적, 다른 레인, 아직 도달하지 않은 먼 적은 맞지 않는다. 관통은 여전히 서로 다른 두 적까지만 적용된다.
- Stage 2 시드 3958, 0원 시작과 실제 하늘 돈·웨이브로 검증한다. 34.233초에 첫 적 x=926.875일 때 7열 중심 x=926에 초보약사를 배치하면, 5초 후 첫 적이 200→140 피해를 받고 뒤 적은 200을 유지한다. 예전에는 첫 적은 200이고 뒤 적만 140이었다.
- 연고칼은 range=165 하나를 감지·피해 두 판정이 공유한다. 바로 앞 칸 직원에게 멈춘 적과의 약 158 거리에서 공격할 수 있다. 가격·피해·공격 주기는 유지하며 166 거리의 적은 공격하지 않는 경계 검사도 추가했다.

## 측정 방법과 한계

- 원시 결과: qa/redesign-balance-v2.json. 규칙 50/50 통과. 기존 43개 규칙을 유지하고 근접 충돌·직원 조합·경계·확정 소개·메타데이터 검사 7개를 추가했다.
- 시드: 각 단계 ID × 1979 + [0, 17, 91]. 기본 전략 60회와 planInput을 0.5초마다 한 번 수행하는 전략 60회다. 두 방식 모두 돈·카드 쿨다운·점유·경찰·실제 승리 조건을 적용한다. 각 전략 59/60, 59/60 승리했다.
- 0.5초는 돈 수집 또는 배치/제거 한 동작의 간격이다. 카드 선택과 칸 클릭을 별개 물리 입력으로 모델링한 것은 아니다. 이벤트는 자동으로 닫으며 화면 판단·손 실수·기기 지연·실제 재미를 측정하지 않는다. 정상 덱·자금을 사용하는 시뮬레이션 검사이지 사람의 완주 인증이 아니다.
- 검사 전략은 갑옷을 보면 돌돌이를 먼저 고려하고, 연고칼은 직원 앞이 아닌 바로 뒤에 배치하도록 조정했다. 이는 안내된 조합을 따르도록 한 것으로 모든 특수 유닛이나 모든 가능한 전략을 평가하지 않는다.
- 0.5초 전략의 1–6단계 18회는 모두 경찰 없이 승리했다. 7단계부터 일부 조합·시드에서 경찰에 의존한다. 19단계 +17 시드는 두 전략 모두 패배했다. 후반 압력과 시드 민감도를 숨기지 않고 남겼으며 모든 시드를 무조건 통과하도록 수치를 맞추지 않았다.
- 중후반의 갑옷이나 남은 고체력 적 처리 때문에 예상 시간을 넘기는 경우가 있다. 9단계 기본 전략 최대258초, 12단계 0.5초 전략 최대268초, 18단계 최대297초, 보스전 최대339초를 기록했다. 실제 사람 플레이로 특히 이 구간과 19단계를 추가 확인해야 한다.
