# 음악 편곡·음색 개선 · 2026-09-09

## 변경
6개 독창적16마디 테마. 도입부의 악기 수를 줄이고 중반 반주 추가, 변주와 마무리 구성. 화음별 장단3도와 도미넌트 연결. 마림바/첼레스타/피치카토/리드/베이스/패드의 배음·필터·엔벌로프를 따로 설계. 코드로 만든 노이즈 타악기, 스테레오 패닝, 짧은 합성 룸 잔향. 마스터 컴프레서 추가. 강한 웨이브에 추가 타악기, 종료 시 감쇠. 음악48보이스 제한, 일시정지/장면 전환 시 정리.

## 파일
src/music.js: 악보 및 편곡. src/instruments.js: 합성 악기/잔향. src/audio.js: 실제 게임 연결/음량/전환. audio-previews/*-v10.wav: 각 테마 청취용 스테레오 미리듣기(외부 에셋 아님, Git 제외).

## 검증
OfflineAudioContext로 실제6곡 PCM 렌더. 약30~44초. 원본 peak0.31~0.38, RMS0.059~0.071; 무음/클리핑 없음. 미리듣기는 peak0.8로 음량 정규화했으며 게임은 사용자 설정 음량을 따름. 실제브라우저에서 음악 생성, 일시정지 후 음악/SFX보이스0, 재개 시 과거음 몰림 없음, 연속테마 전환 검사. 게임규칙38개/20스테이지 자동전략 통과.

음향 수치와 재생 동작을 검증한 것이며, 사람의 청감이나 상업용 사운드트랙 수준을 보증하지 않음. 미리듣기로 음악 취향/반복 피로 확인 가능.
